## 编程求以孩子兄弟表示法存储的森林的叶子结点数

```c
int leavesOfTree(Tree T){
    if(T==NULL) return 0;
    if(T->firtChild==NULL) return 1+leavesOfTree(T->nextSibling);
    else return leavesOfTree(T->firtChild)+leavesOfTree(T->nextSibling);
}
```

## 以孩子兄弟链表为存储结构，请设计递归算法求树的深度

```c
int heightOfTree(Tree T){
    if(T==Null) return 0;
    int fch=heightOfTree(T->firtChild); // 第一个孩子的深度
    int nsh=heightOfTree(T->nextSibling); // 兄弟深度
    if(fch+1>nsh) return fch+1;
    else return nsh;
}
```
