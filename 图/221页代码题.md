## 【2021统考真题】已知无向连通图G由顶点集V和边集E组成，|E|>0，当G中度为奇数的顶点个数为不大于2的偶数时，G存在包含所有边且长度为|E|的路径（称为EL路径）。设图G采用邻接矩阵存储，类型定义如下：

```c
typedef struct {
	int numVertices, numEdges; // 定点数和边数
	char VerticesList[MAXVERTEXNUM]; // 顶点表
	int Edge[MAXVERTEXNUM][MAXVERTEXNUM]; // 边表
}MGraph; // 矩阵
```

## 请设计算法 int IsExistEL(MGraph G)，判断是否存在EL路径，若存在，则返回1，否则返回。要求：

（1）给出算法的基本设计思想

遍历边表，定义一个遍历degree记录当前结点的度，在定义一个变量count记录度为奇数的顶点个数，又因为EL路径的条件是度为奇数的顶点个数是小于2的偶数，所以当count等于 0或等于2时，EL路径存在

（2）根据设计思想，采用C或C++语言描述算法，关键之处给出注释

```c
int IsExistEL(MGraph G) {
	int degree = 0; // 记录当前结点的度
	int count = 0; // 记录度为奇数的结点个数
	for (int i = 0; i < G.numVertices; i++)
	{
        for (int j = 0;j < G.numEdges;j++) {
            degree += G.Edge[i][j];
        }
		if (degree % 2 == 1) { // 判断当前结点度是否为奇数
			count++;
		}
	}
	return count == 0 || count == 2 ? 1 : 0;
}
```

（3）说明你所设计算法的时间复杂度和空间复杂度

时间复杂度：o(n^2) 空间复杂度：o(1)

## 请设计算法int printVertices(MGraph G)，对给定得任意非空有向图G，输出G中所有得K结点，并返回K顶点得个数。要求：

（1）给出算法的基本设计思想

遍历边表，并计算出度入度，比较出度入度，如果入度大于出度K+1，并打印结点

（2）根据设计思想，采用C或C++语言描述算法，关键之处给出注释

```c
int  printVertices(MGraph G) {
    int in = 0; // 入度
    int out = 0; // 出度
    int K = 0; // 出度大于入度的结点数
    for (int i = 0;i < G.numVertices;i++) {
        in = 0;
        out = 0;
        // 计算出度
        for (int j = 0;j < G.numVertices;j++) {
            if (G.Edge[i][j] == 1) out++;
        };
        // 计算入度
        for (int n = 0;n < G.numVertices;n++) {
            if (G.Edge[n][i] == 1) in++;
        }
        if (out > in) {
            printf("顶点：%c\n", G.VerticesList[i]);
            K++;
        } 
    }
    return K;
}
```
