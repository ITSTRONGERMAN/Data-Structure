## 写出折半查找的递归算法。初始调用时low为1，high为ST.length

```c
int binarySearch_recursion(LinearSearchTable T, ElementType target, int low, int high) {
	if (low > high) return -1; // 找不到目标
	int mid = (low + high) / 2; // 计算中间值

	if (T.data[mid] == target) return mid; // 找到目标值
	else if (T.data[mid] > target) {
		return binarySearch_recursion(T, target, low, mid - 1); // 搜索左半部分
	}
	else {
		return binarySearch_recursion(T, target, mid + 1, high); // 搜索右半部分
	}
}
```

## 线性表中各结点的检算概率不等时，可用入下策略提高检索效率，若找到指定的节点，则将该结点和其前驱的结点（若存在）交换，使得经常被检索得结点尽量位于表得前端。试设计在顺序结构和链式结构得线性表上表现上述策略得顺序检索算法

```c

int search(LinearSearchTable* T, ElementType target){
	T->data[0] = target;
	int i;
	for (i = T->length; T->data[i] != target && i > 0; i--);
	if (i < T->length && i>1) {
		ElementType temp = T->data[i];
		T->data[i] = T->data[i - 1];
		T->data[i - 1] = temp;
		return  i - 1;
	}
	else return -1;
}
```

## 已知一个n阶矩阵A和一个目标值k。该矩阵无重复元素，每行从左到右升序排序，每列从上到下升序排列。请设计一个时间上尽可能高效的算法，判断矩阵中是否存在目标值k。例如，

$$
\begin{bmatrix}
1 & 4 & 7 \\
2 & 5 & 8 \\
3 & 6 & 9
\end{bmatrix}
$$

## 目标值为8，判断存在。要求：

（1）给出算法的基本设计思想

定义两个指针i、j分别代表矩阵的行和列，当matrix(i , j)>k时，j向左移，否则 i 向下移，直至找到目标k未

（2）根据设计思想，采用C或C++语言描述算法，关键之处给出注释

```c
int matrixSearch(int matrix[][], int n, int k) {
	int i = 0, j = n-1;

	// 从左上角开始
	while (i < n && j > 0) {
		if (matrix[i][j] == k) {
			// 找到目标元素，返回位置
			return 1;  // 或者返回(i, j)的坐标
		}
		else if (matrix[i][j] > k) {
			// 当前元素小于目标值，往左移动
			j--;
		}
		else {
			// 当前元素大于目标值，往下移动
			i++;
		}
	}

	// 未找到目标元素
	return 0;
}
```
